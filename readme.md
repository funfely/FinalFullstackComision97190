# API de Adopciones - Proyecto Final Fullstack

API REST optimizada para la gestión de adopciones, desarrollada en Node.js y Express, automatizada mediante arquitectura de contenedores Docker y flujos de Integración Continua (CI/CD).

## Enlaces del Proyecto
* **Repositorio de Código (GitHub):** https://github.com/funfely/FinalFullstackComision97190.git
* **Contenedor Público (Docker Hub):** https://hub.docker.com/r/jecordero/adoption-api
